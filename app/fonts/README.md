# Local ONI Typefaces

Copied without modification from the team's `ONI_content/ONI_brand /fonts/`:

- `Bounded-Variable.ttf`: Bounded by Vlad Churkin, weight axis 200-900.
  Landing display text uses the actual Bold instance at weight 700.
- `CascadiaCodePL-Regular.otf`: Cascadia Code PL, weight 400.
- `CascadiaCodePL-SemiBold.otf`: Cascadia Code PL, weight 600.

The original font binaries retain their embedded copyright and license notices.
Bounded declares SIL Open Font License 1.1; Cascadia includes Microsoft's
OFL-based license in its name table.

`next/font/local` owns loading and generated CSS variables. No external font
service is used for these typefaces. Bebas Neue remains available to legacy
sections; the brandbook retains its route-scoped typefaces.
