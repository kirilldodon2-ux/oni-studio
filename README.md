# ONI Studio

Cinematic studio system — living archive, experimental publishing space, and editorial
environment.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS v3
- Framer Motion
- Three.js / React Three Fiber
- Cloudflare Pages

## Philosophy

- cinematic calmness
- editorial rhythm
- restrained motion
- atmosphere over feature count
- systems over hacks

## Current Priority

Phase 4 — Cinematic Polish (in progress)  
Phase 5 — Navigation System (in progress)

## Local Development

```
npm install
npm run dev
```
